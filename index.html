How it works

One checkpoint.
Three clear outcomes.

Before an agent’s requested action reaches a protected tool, evaluate it against your workspace policy. The result tells your trusted application what to do next.

✓ALLOW — the action matches an enabled policy.
◷REQUIRE_APPROVAL — pause for a human decision.
×DENY — the action does not meet the policy.

Important: a policy response alone does not execute or secure a tool call. Your server-side execution path must enforce the decision and prevent bypasses.

Python · policy evaluation
import os
import httpx

response = httpx.post(
    os.environ["GUARDRAIL_URL"] + "/v1/evaluate",
    headers={"X-API-Key": os.environ["GUARDRAIL_API_KEY"]},
    json={
        "agent_id": "support-agent",
        "action": {"tool": "read_order", "order_id": "order_123"},
    },
    timeout=5.0,
)
response.raise_for_status()
decision = response.json()
if decision["decision"] != "ALLOW":
    raise PermissionError(decision["reason"])
# A trusted server must enforce this decision.

FAQ

Good questions. Clear answers.

Does Guardrail execute tool calls?

The current app evaluates actions, records policy decisions, and manages approval workflows. Tool execution must be implemented in a trusted server-side gateway that enforces the decision.

Can I connect it to live payments or customer data today?

Do not connect live systems yet. Use the sandbox and sample handlers while you validate the architecture. Complete an independent security review and integration testing before handling real money or personal data.

Does an approval automatically perform the action?

No. An approval records a human decision. Your trusted executor must verify the exact approved action and securely handle execution, retries, and provider-specific failure cases.

Can I use Guardrail with MCP tools?

The project includes an MCP-oriented sandbox integration pattern. It is a starting point for integration testing, not a claim of compatibility with every MCP client or a production-ready gateway.

What happens if an agent tries an unknown tool?

The example policy model is designed to fail closed for unknown tools and unregistered or disabled agents. Validate the policies and every protected execution path for your actual deployment.
